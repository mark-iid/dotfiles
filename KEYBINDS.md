# ⌨ niri Hotkey Cheatsheet

`Mod` = **Super**. Raw bind list: **`Mod+Shift+/`**. Source: `niri/.config/niri/config.kdl`.

## 🚀 App launchers
| Key | App |
|---|---|
| `Mod+Return` | Terminal (ghostty) |
| `Mod+D` | Launcher (fuzzel — any app by name) |
| `Mod+B` | Browser (Firefox) |
| `Mod+E` | Files (Thunar) |
| `Mod+N` | Notes (Joplin) |
| `Mod+P` / `Mod+O` | Passwords / TOTP (rbw → clipboard) |
| `Mod+G` | Comms screen: Evolution ∣ Slack / Discord |
| `Mod+C` | VS Code ˡ |
| `Mod+M` | Music (Supersonic) ˡ |

## 📻 Ham radio ˢ
| Key | App |
|---|---|
| `Mod+W` | **W**SJT-X (FT8/FT4) |
| `Mod+S` | **S**tation log (QLog) |
| `Mod+A` | **A**ll-mode digital (fldigi) |
| `Mod+I` | **I**nbox — Winlink: VARA + `pat http` + browser |

## 🪟 Windows
| Key | Action |
|---|---|
| `Mod+Q` | Close |
| `Mod+H` `J` `K` `L` *(or arrows)* | Focus left / down / up / right |
| `Mod+Shift+←↓↑→` | Move window / column |
| `Mod+F` / `Mod+Shift+F` | Maximize column / fullscreen |
| `Mod+R` | Cycle column width (⅓ → ½ → ⅔) |
| `Mod+Shift+X` | Un-stick a self-fullscreened X11 app |

## 🗂 Workspaces
| Key | Action |
|---|---|
| `Mod+1`…`4` | Switch to workspace |
| `Mod+Shift+1`…`4` | Move column to workspace |
| `Mod+PgUp` / `PgDn` | Previous / next workspace |
| `Mod+wheel` | Previous / next workspace |
| `Mod+Shift+wheel` | …dragging the focused column along |

## 🖥 System
| Key | Action |
|---|---|
| `Mod+V` | Clipboard history |
| `Mod+Escape` | Lock |
| `Mod+Shift+C` | Caffeine (block idle-lock + suspend) |
| `Mod+Shift+G` | Game mode (touchpad disable-while-typing) ˡ |
| `Mod+Shift+P` | Power off monitors |
| `Mod+Shift+E` | **Quit niri** |
| `Mod+/` | This cheatsheet |
| `Print` / `Ctrl+Print` / `Alt+Print` | Screenshot region / screen / window |

## 🎤 Voice ˡ
| Key | Action |
|---|---|
| `Mod+T` | Dictation — speaks into the focused window |
| `Mod+Shift+T` | Command mode (toggle) |

Phrases: **focus**/**move** *left·right·up·down* ∣ **close window** ∣ **full screen** ∣ **maximize** ∣ **center** ∣ **next**/**previous workspace** ∣ **workspace** *one…nine*

## 🎛 Hardware keys ˡ
Volume / mute (`wpctl`) · brightness (`brightnessctl`) · ⏯ ⏭ ⏮ (`playerctl`)

---
ˡ laptop only · ˢ shack PC only — hostname-guarded or not installed, so the key does nothing on the other machine.
